# Changelog

## 1.2.0-beta.1

First public experimental release, derived from the private 1.1.0 patch.

- Standard Java 21 / NeoForge Gradle build and a minimal activation-pack asset.
- Strict tested dependency versions and the existing marker/height opt-in.
- Separate, testable surface-defaults lifecycle state, including restoration
  of an originally null default and recovery before a subsequent server start.
- Structured logging, English/Chinese documentation and MIT licensing for
  original project code.

The scope remains surface-rule preservation. No third-party biome tables,
terrain data packs, Minecraft binaries, or dependency JARs are distributed.
